# nearby-notices.github.io

The GitHub Pages front for [Nearby Notices](https://github.com/Nearby-Notices/nearby-notices): public notices near you in plain English, with food hygiene ratings on the map.

https://nearby-notices.github.io shows the live service in a frame, so it can be reached from networks that block newly registered domains. The service itself is at https://nearbynotices.co.uk. A search can be linked directly, for example https://nearby-notices.github.io/?place=Inverness&distance=3&unit=mi

Independent, not an official service.
